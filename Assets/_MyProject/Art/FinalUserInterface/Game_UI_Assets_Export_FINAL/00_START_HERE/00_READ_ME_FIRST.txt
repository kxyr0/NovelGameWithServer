НАЧАТЬ ЗДЕСЬ

1. 00_READ_ME_FIRST.txt - коротко объясняет, что где лежит.
2. 01_UNITY_BORDERS_TABLE.txt - значения для Unity Sliced Image.


Главный вариант для Unity:
01_PNG_FULL
Там лежат цельные PNG. Обычно для таких UI-плашек в Unity берут цельный PNG как один Sprite и включают Image Type: Sliced.
Так можно менять размер плашки, сохраняя углы, края и декоративные элементы.

Отдельные части:
03_CUT_PARTS_PNG
Там лежат отдельные PNG-части, вырезанные из цельных PNG.
Если удобнее работать с частями или они понадобятся для особой сборки, их можно взять отсюда.

Справочные карты нарезки:
04_CUT_PARTS_REFERENCE
Это визуальная подсказка по нарезке. По ней удобно увидеть, где фиксированные края, а где растягиваемая середина.

Векторные исходники:
02_SVG_SOURCE
Это SVG-исходники для правок. Простые ассеты лежат одним SVG. Сложные ассеты могут лежать слоями в папке layers, чтобы сохранить редактируемую структуру.

Превью:
05_PREVIEWS
Там лежат контакт-листы и проверочные картинки, чтобы быстро посмотреть ассеты глазами.

Ссылка на Figma:
06_FIGMA_REFERENCE
Там лежит ссылка на исходный Figma-файл.

Что использовать в первую очередь:
01_PNG_FULL
01_UNITY_BORDERS_TABLE.txt

Если нужны отдельные части:
03_CUT_PARTS_PNG

Если нужны векторные исходники:
02_SVG_SOURCE


Важно:
Border values подходят именно для PNG из этой папки. Если UI-элемент просто растягивается в Unity, значения не меняются. Если PNG заново экспортировать в другом размере, значения нужно пересчитать пропорционально.
