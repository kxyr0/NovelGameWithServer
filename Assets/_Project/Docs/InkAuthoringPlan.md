# Ink для сценаристов и Unity

## Короткий ответ

Да, Ink можно использовать, но лучше не заменять им текущий движок истории напрямую.
В проекте уже есть свой StoryGraph, узлы сцен, выборов, премиума, гардероба, статов,
картинок, музыки и публикации на backend. Поэтому самый безопасный путь:

1. Сценаристы пишут текст и ветвления в `.ink`.
2. Unity импортирует `.ink` через `ink-unity-integration`.
3. Наш editor-инструмент читает скомпилированный `storyJson`.
4. Конвертер создаёт текущий формат проекта: StoryGraph или JSON эпизода для backend.

Так сценаристы получают удобный текстовый формат, а игра не теряет существующие системы.

## Почему не сразу заменить всё на Ink runtime

Ink отлично ведёт диалоги, ветвления, переменные и условия. Но текущий проект делает
больше, чем чистый текст:

- сцены и фоны;
- персонажи и позиции;
- музыка, звуки, видео и картинки;
- платные выборы и свечи;
- гардероб;
- публикация эпизодов через backend;
- сохранения и прогресс в текущем формате.

Если пустить Ink напрямую в runtime, придётся заново связывать эти системы с Ink.
Если использовать Ink как авторский формат с импортом в StoryGraph/JSON, риск меньше.

## Рекомендуемый формат для сценаристов

Текст и выборы писать обычным Ink. Технические действия писать тегами:

```ink
# scene: street_evening
# bg: /media/background_street.webp
# music: /media/rain_theme.ogg

Анна: Ты правда пришёл?

* [Сказать правду]
    # stat: trust +1
    Я не мог иначе.

* [Промолчать]
    # premium: candles 5
    ...
```

Теги можно валидировать автоматически: если указан `/media/...`, инструмент проверяет,
что файл есть на сервере или хотя бы выглядит как публичная ссылка.

## Что нужно сделать для полноценного внедрения

1. `ink-unity-integration` подключён через Unity Package Manager.
2. Папка для сценариев создана: `Assets/_MyProject/Ink`.
3. В Unity есть меню `VN/Ink/Создать пример Ink`.
4. В Unity есть меню `VN/Ink/Экспорт выбранного Ink в Story JSON`.
5. Экспорт создаёт обычный Story JSON, после чего срабатывает текущий JSON importer проекта.
6. Следующий слой - расширять теги `stat`, `premium`, `media`, если сценаристам нужно больше автоматизации.

## Вывод

Ink использовать можно и полезно. Но в этом проекте его лучше внедрять как удобный
формат написания и импорта, а не как моментальную замену текущего визуального движка.
