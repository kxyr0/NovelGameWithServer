# Инструкция по серверу Nocturnal

Этот документ нужен, чтобы не держать весь процесс в голове. Его можно открыть из Unity:
`Инструменты -> Nocturnal -> Сервер -> Инструкция`.

## Смысл Тест и Прод

`Тест` (Stage) - тестовый мир. Сюда сначала кладём новые серии, JSON, Addressables и проверяем, что ничего не сломалось.

`Прод` (Prod) - официальный мир. Это видят реальные игроки. Сюда попадает только то, что уже проверено на тестовой среде или локальном mock-сервере.

Главное правило: сначала локальная проверка или тестовая среда, потом Прод.

## Что где живёт

- История создаётся через `POST /admin/catalog/story`.
- Сезон добавляется через `POST /admin/catalog/story/{storyId}/season`.
- Эпизод добавляется через `POST /admin/catalog/season/{seasonId}/episode`.
- JSON эпизода уходит в backend через `POST /admin/catalog/episode/{episodeId}/content`.
- Публикация/скрытие истории идёт через `PATCH /admin/catalog/story/{storyId}/publish`.
- Публикация/скрытие эпизода идёт через `PATCH /admin/catalog/episode/{episodeId}/publish`.
- Каталог для проверки берётся через `GET /admin/catalog`.
- Медиа-файлы загружаются отдельно через `POST /admin/media/upload`, список берётся через `GET /admin/media`, удаление идёт через `DELETE /admin/media/{filename}`.
- Публичная ссылка для игры выглядит как `https://nocturnedc.ru/media/{filename}` и не требует авторизации.
- Addressables-бандлы и remote catalog собираются Unity и загружаются по upload plan, когда будет готов CDN/R2.
- На 2026-07-14 CDN/R2 для Addressables ещё не готов. Пока можно собирать manifest и upload plan, но реальные Addressables-файлы не считаем выложенными.
- `X-Admin-Key` не хранится в проекте. Его вводим вручную в окне или держим в `NOCTURNEDC_ADMIN_KEY`.

## Локальная проверка без риска

1. Открой `Инструменты -> Nocturnal -> Сервер`.
2. Нажми `Локальная проверка`.
3. Убедись, что в ответе есть создание истории, добавление сезона, добавление эпизода, загрузка JSON, публикация и получение каталога.
4. Если smoke не проходит, на реальный сервер ничего не отправляем.

## Проверка новой серии

### Медиа перед JSON

1. Перейди во вкладку `Медиа`.
2. Укажи `Адрес сервера`: `https://nocturnedc.ru`.
3. Вставь `X-Admin-Key`.
4. Выбери файл `png`, `jpg`, `jpeg`, `webp`, `mp3`, `ogg`, `wav` или `mp4` до 50MB.
5. Нажми `Загрузить файл`.
6. Скопируй публичную ссылку `/media/...` или `https://nocturnedc.ru/media/...` и используй её в JSON эпизода, Ink-тегах или описании сцены.

1. Выбери `Тест`.
2. Нажми `Применить среду`.
3. Нажми `Проверить настройки`.
4. Нажми `Собрать Addressables`.
5. Нажми `Собрать manifest`.
6. Нажми `План загрузки`.
7. Если R2/CDN уже выдан, загрузи файлы из upload plan. Если нет, продолжай проверку backend/JSON/media, но не считай Addressables опубликованными.
8. Заполни `ID истории`, `Название истории`, `ID сезона`, `Название сезона`, `ID эпизода`, `Название эпизода`.
9. Нажми `Создать историю`, потом `Добавить сезон`, потом `Добавить эпизод`.
10. Выбери JSON эпизода и нажми `Загрузить JSON эпизода`.
11. Нажми `Получить каталог` и проверь, что история/сезон/эпизод появились.
12. Нажми `Опубликовать историю`, потом `Опубликовать эпизод` только если всё проверено.

## Выкладка в Прод

1. Выбери `Прод`.
2. Проверь, что `Адрес сервера` указывает на `https://nocturnedc.ru`.
3. Снова сделай `Проверить настройки`, `Собрать Addressables`, `Собрать manifest`, `План загрузки`.
4. Нажми `Отчёт готовности`.
5. Если есть блокирующие ошибки, остановись и исправь.
6. Если R2/CDN уже выдан, загрузи файлы из Prod upload plan. Если нет, Прод-публикацию релиза с удалёнными Addressables не делаем.
7. Создай/проверь историю, сезон и эпизод.
8. Загрузи JSON эпизода.
9. Нажми `Получить каталог`.
10. Нажми `Опубликовать историю`, потом `Опубликовать эпизод`.

## Полезные кнопки

- `Локальная проверка` - быстрый тест связки на локальном сервере.
- `Создать историю`, `Добавить сезон`, `Добавить эпизод` - создают черновую структуру каталога.
- `Опубликовать историю`, `Опубликовать эпизод` - отдельно открывают контент игрокам; удалённая запись всегда просит подтверждение и показывает выбранную среду.
- `Предпросмотр запросов` - показывает маршрут и JSON без отправки запроса на сервер.
- `Скопировать ответ` - копирует последний предпросмотр, проверку или backend-ответ.
- `Скопировать API-команды` - команды для ручной проверки backend API; они останавливаются, если `NOCTURNEDC_ADMIN_KEY` пустой, JSON эпизода не найден, запрос упал или сервер вернул HTTP-ошибку.
- `Скопировать чеклист` - короткий чеклист перед публикацией, включая ключ администратора, проверку проекта и сверку среды/сервера.
- `Текст передачи` - полный текст для передачи человеку: сервер, маршруты, чеклист, команды.
- `Применить среду` - переключает Unity/Addressables и подставляет `Адрес сервера` под выбранную среду.
- `Отчёт готовности` - отчёт о готовности тестовой или реальной выкладки.
- `Проверить проект` и `Открыть отчёт` - локальная проверка маршрутов, payload, инструкции и лимитов.

## Когда не нажимать Publish

- Не прошла `Локальная проверка`.
- Не собран manifest.
- Нет upload plan.
- Не загружены Addressables-файлы или ещё не выдан CDN/R2 для их загрузки.
- `Тест` выбран, но `Адрес сервера` указывает на `nocturnedc.ru`.
- `Прод` выбран, но `Адрес сервера` не production.
- Нет `X-Admin-Key`.
- Нет `ID истории` или `ID эпизода` перед публикацией/скрытием.

## Минимальная схема процесса

```text
Контент Unity -> сборка Addressables -> manifest -> план загрузки -> загрузка файлов
Черновик каталога -> JSON эпизода из Unity -> загрузка в backend -> проверка каталога -> публикация
Проверка в Тест -> повтор в Прод -> реальные игроки
```
